# 四条业务线的对外口径（用户亲口给的切法，2026-09-24）

写案例、对外材料、宣传文案时**照这份切法**，不要自己重新分类（我曾按数据流阶段自己发明「精炼」，被当场纠正）。

## 量潮数据（qtdata）

面向高校科研团队与高新科技企业的数据处理服务。三段：**采集 → 清洗 → 大模型挖掘**。

- **采集**：把散在互联网和客户系统里的原始数据完整稳定地拿下来。代表案例＝高频电商价格采集（前身厦门大学 China's Prices Project 十年积累：天猫／京东 1000 余个关键词、约 500 万数据点／日）。反爬强度是报价前必评项
- **清洗**：把散在不同系统、不同格式里的数据弄干净、对齐。代表案例＝制衣厂生产效率数据合并（几百份工人/班组长问卷 + 产量表 + 工序表 + 返工考勤，按款号/日期/员工合并；依据 `产值 = 员工 × 工序 × 产量`）。问卷侧：多打一个 0、正反向计分混用、低质量答卷要先与研究者商定判定标准
- **大模型挖掘**（**正名，原文是 brochure 场景一「大模型文本挖掘」**）：用大模型把非结构化文本变成结构化信息。代表案例＝电商评论挖掘（采集评论 → 两遍处理：先摘成小句、再归类总结 → 输出消费者评价维度）。质量按**分类抽检准确度**计价（准确度越高费用非线性增长）；企业侧需求＝从大规模非结构化数据提取信息用于知识库或模型训练；工程难点在**把流水线组装起来**，不在单环节

## 量潮课堂（qtclass）

两类形式：**校企合作**——把课程体系整体带入学校，代表案例＝浙江理工大学计算机系的一系列合作（大数据导论实践课，源于 CPP 课题十年积累）；**社会招生**——以**量潮实训基地**为载体按人培养，含免费、付费、VIP 等多种形式（免费走评审制、脱胎于招聘考核；付费核心形态是一对一授课；一条规矩：付费与免费用同一套考核标准）。培养路径三段：学员 → 实训 → 实习

## 量潮云（qtcloud）

两类产品：**SaaS**——提高管理的透明度和管理效率（知识工作云 qtcloud-work：CLI + 工作台；管理后台 qtadmin：业务域带 `qt` 前缀、职能域不带）；**PaaS**——在软件上提高工程质量和工程效率、使协同更友好（量潮 DevOps 云命令行工具：把发布流程从 AI Skill 固化为确定性规则引擎，开源 v0.4.x 内测、不建议生产使用；`code` 命令＝submodule 单仓管理；契约驱动研发流程＝清洗精炼数据 → 知识建模 → 半结构化契约驱动各端独立开发 → 数据回写档案）

## 量潮咨询（qtconsult）

两类服务：**创业咨询**——面向刚开始创业的人，提供管理方法上的帮助和辅导（一对一战略对话／日常咨询／月度经营分析报告；核心方法论＝帮客户建立自己的「第二大脑」系统）；**创新咨询**——偏技术一侧，通过数字化升级、智能化改造帮助企业提高效率（调研 → 分析 → 决策 → 执行；OODA 作适应环；交付客户可看的看板）。难点不在实施，在**把客户说不清的真实需求理清楚**

# 跨仓取材地图（同一件事的各版本）

| 仓库 | 视角 | 适合拿什么 |
|---|---|---|
| `data/brochure/<业务>/` | 客户视角 5W1H（who/what/when/how） | 场景、卖点、对外口径第一来源；**含价格与内部讲课语，不能整段上公开页** |
| `docs/tutorial/<业务>/` | 简介 | 定位、客户结构、商业模式、当前关键问题 |
| `docs/handbook/<业务>/` | 操作手册 | 流程、阶段、清单、角色、话术模板 |
| `docs/essay/<业务>/` | 主张随笔 | 「为什么」（如「企业咨询是最脏的一块业务」）——取观点不取措辞 |
| `data/profile/<业务>/` | 业务档案 | 服务对象、定价、当前阶段（**价格只在这里用，不上公开页**） |
| `data/intention/<业务>/` | 意图 | 定位与将来（如咨询＝总控制台、流程显性化「哪怕只是内部案例也比展示不出来强」） |
| `data/archive/gallery/<业务>/` | 交付原件 | scope／blueprint／quotation／delivery 全套——**案例的原料**，压成三五行后才进案例库 |
| `domains/quanttide-strategy/data/profile/<业务>/` | 战略 | 方向、商业形态（**内部语汇，慎用**） |

# 判例

- 「精炼」→「大模型挖掘」：用户纠正「精炼这类不太对。这类经常是需要使用大模型」——**分类要指认交付方式，不是抽象阶段**
- 「问卷清洗」与「制衣厂四源合并」本是同一个案子（brochure `what.md` 里同一位研究者）——写之前先把各仓的同一案子对上号，别拆成两件事
- 价格倍数（60% 基准／80% 1.5–2 倍／90% 3–5 倍）出自内部讲课底稿：**写公开页时压住不写**，只写「准确度越高、费用非线性增长」
